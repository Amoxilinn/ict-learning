## 高风险区域（待逐一复现）

1. **固定侧栏 + 长学习目录**：桌面 242px / 210px 固定宽，九阶段 94 章目录很长；缩放或矮屏时依赖 `overflow-y:auto`，可能出现底部内容被截断或滚动条不明显。
2. **断点切换**：1150px 隐藏右侧 TOC、800px 隐藏侧栏、520px 调整字号；在 125%/150% 浏览器缩放下，实际 CSS 宽度会跨断点，可能出现“桌面布局但看不到目录”或“移动布局但字号过大”。
3. **术语首现提示**：正文中插入 `button.term-button` 与括号提示，改变行内盒模型；不同字体/缩放下行高、换行、标点位置可能不齐。
4. **教学组件内部滚动**：拓扑 `min-width:530px`、报文/表格在窄容器内横向滚动；滚动条样式、边缘裁切在真实浏览器可能看起来像“内容被截断”。
5. **`html,body{overflow-x:hidden}`**：可能把真实溢出隐藏掉，而不是让组件内部滚动；需要确认没有内容被裁切。
6. **字体回退**：macOS 使用 PingFang SC，Windows 回退 Microsoft YaHei；相同字号下字宽不同，可能导致标题换行、表格列宽、按钮文字溢出。
7. **打印/PDF**：打印样式隐藏侧栏和交互，但没有逐章检查分页、表格、折叠内容。
8. **移动端真实浏览器**：未在 iOS Safari / Android Chrome 检查动态视口、地址栏收起、软键盘和触控滚动。
