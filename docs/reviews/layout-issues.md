# 阅读布局问题 · 修复与验收记录

更新：2026-10-25。用户要求直接检查 Chrome 后，已修复可确认的样式与布局问题，并完成本轮 Chrome/多视口验收。详细结果见 [验收报告](polish-2026-10-25.md)。

## 确认原因与修复

1. `level-core/advanced/detail` 同时作用于正文 section 与标签 span，给正文带来大片背景和边框。颜色规则已限定到 `.level-badge.level-*`。
2. `html,body{overflow-x:hidden}` 会隐藏真实溢出，已移除；改为各图示容器内部滚动，flex/grid 子项允许收缩，长词断行。
3. 移动侧栏原来没有遮罩、背景禁用和焦点循环，容易覆盖正文且键盘进入背景。现统一开关遮罩、背景 inert、滚动锁定、aria-expanded、Escape 和焦点归还，跨桌面断点自动关闭。
4. 顶部工具、目录条目、图示状态表与长链接在窄屏独立换行，滚动区域可键盘进入；图示切步不再丢失横向滚动位置。
5. 三端时序原箭头横跨整个栏位，不能体现中间端点；现按发送/接收位置定位并给出端点文字。
6. 原字号按钮会被正文更具体的规则覆盖；修正优先级后 390px 下实测为 17px/13px。
7. 打印通过 beforeprint 展开详情并初始化实验，afterprint 恢复，避免答案/配置缺页；实验结果保留，控制按钮隐藏。

## 本轮验证

- 内置浏览器 94 章 × 1280/1024/768/500/390px，470 组，正文无背景串用且无整页横向溢出。
- 首页/目录/资料与代表章节另外检查 110 组；22 个可选场景桌面/窄屏共 266 步与重置通过。
- 实际 Google Chrome 100/125/150% 下 VLAN 页面无重叠、非预期裁切，侧栏/右目录按断点显隐；打印预览包含配置、答案与实验状态，取消后恢复折叠。
- 四个操作实验、搜索、术语弹窗、学习标记刷新/取消、移动目录键盘操作及图示键盘滚动保留通过。
