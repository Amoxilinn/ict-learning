# 领域教学内容抽读记录

日期：2026-10-24
方法：每领域抽取 4—8 个知识点，对照旧稿技术结论、标准流程和页面呈现，检查方向、层次、条件、顺序、数字、命令前提与章节衔接。只记录确认问题与残余不确定点。

## 数通基础 / 交换 / 路由

抽读：ICT-001.01—.02、002.01—.09、003.01—.02、004.01—.02、005、007、009.01、010.01、013、015、016。

确认要点：

- TCP 三次握手的两端状态时点、SYN 占一个序号、最后 ACK 丢失分支，与 RFC 9293 的通用流程一致。
- ARP 只解析下一跳；同网段问目的主机，跨网段问网关；缓存更新发生在收到响应之后。
- 交换机先学源 MAC、再查目的 MAC；未知单播泛洪排除入端口；目的 MAC 不会被学习。
- VLAN Access/Trunk、PVID、允许列表、VLANIF 依赖活动二层成员，方向正确。
- 链路聚合逐流分担、成员故障后逻辑口仍 up 但容量下降；STP 根桥/根端口/阻塞端口顺序正确；RSTP 边缘端口条件、MSTP 区域一致性表述正确。
- 最长前缀匹配先于优先级；同前缀才比较优先级/开销；静态路由下一跳递归与回程缺失场景正确。
- OSPF 邻居/邻接、DR/BDR、LSA 同步、区域 0、Full 不等于业务通，表述正确。
- BGP 路径向量、策略选路、RD/RT 分工、VPNv4/VPNv6 场景方向正确。

残余不确定：不同 VRP 版本对 `network` 精确匹配、链路本地下一跳必须带出接口、浮动静态检测的细节；正文已用“通常/按平台”限定。

## 园区安全 / 自动化 / 广域 / VPN

抽读：ICT-024.02—.03、027、028.01—.03、034、035.01/.07/.08、036、037、038、040、041、056、057、058、059、061、062、063、064、065、069、070、060。

确认要点：

- PPP 的 LCP/认证/NCP 阶段、PPPoE 发现与会话、8 字节开销与 1492 MTU 正确。
- VRF 按入口选表、GRE/L2TP/IPsec 分工、IPsec 选择器与 SA、SSL VPN 的应用层接入定位正确。
- AAA 认证/授权/计费分离；802.1X 在地址分配前控制端口；Portal/MAC 认证适用场景正确。
- DHCP Snooping 信任口方向、绑定表、IP Source Guard 依赖绑定表，方向正确。
- VRRP 虚拟地址/优先级/抢占/上行跟踪；BFD 只检测不决策，正确。
- QoS 分类/标记/队列/调度；SNMP/LLDP/NQA 分工；NETCONF 能力协商、YANG、Telemetry 订阅、RESTful 状态码，正确。
- IPsec VPN 选择器、NAT 豁免、双机 SA/会话同步边界、WAF/IPS/内容过滤分工，表述克制。

残余不确定：HWTACACS 与 RADIUS 授权属性差异、SSL VPN 网络扩展路由/DNS 下发、双机切换的版本行为、CloudWAN/SD-WAN 组件命名随版本变化。正文均未写死。

## WLAN

确认要点：

- CAPWAP 控制/数据隧道、AP 上线阶段、FIT/FAT/Leader AP 分工正确。
- 802.1X/Portal/MAC 认证的先后与回退；WPA2-PSK 四次握手、PSK 不做数据密钥、企业认证三方信任，正确。
- 漫游的关联/认证/密钥/转发阶段，二层/三层漫游边界；射频信道/功率/频宽/干扰/容量，正确。

- WLAN Planner 输入/输出/可信边界、CloudCampus APP 扫码与上线区分、规划流程、优化基线，正确。
- 大型 WLAN 分批交付、云管理 WAC/AP 两条路径、传统运维与智能运维边界，正确。

残余不确定：不同 AP/AC 型号对 802.11ax、OFDMA、MIMO、Mesh、定位能力的支持差异；规划工具传播模型与版本界面；云管理断连后的本地转发行为。正文用“按型号/版本核对”限定。

## DCN / 方案

抽读：ICT-042、043、044、045、046、047、048、049、050、051、052、053、054、055、066、067、071、072、073。

确认要点：

- 服务器虚拟化/网络虚拟化/存储三类接口；OpenStack 组件分工（Nova/Neutron/Keystone/Glance/Cinder）；容器共享内核与 Kubernetes 控制面，正确。
- M-LAG 双归与 peer-link、VXLAN 封装/VTEP/VNI、EVPN Type 2/3、RD/RT、分布式网关，正确。
- PFC/ECN 的层次差异、RoCE 无损、训练/推理/HPC 流量形状，正确。
- Leaf-Spine、收敛比、故障态容量、ECMP 逐流，正确。
- 机架出租的资源边界、计算联动、云网对象映射、容器网络三层（Pod/Service/策略），正确。
- 多云多 DC 的地址/路由/故障域、MDC 跨 DC 控制器定位、超简网络与存储网络取舍，正确。
- 云安全责任随 IaaS/PaaS/SaaS 变化、VPC/子网/安全组/实例规则叠加、混合云重叠地址，正确。
- 园区/分支/骨干/云方案章节的“路径完整、许可最小、地址唯一”主线一致。

残余不确定：具体 CloudFabric/CloudCampus 版本的对象名称、菜单和许可；MDC 与多云控制器的产品边界；EVPN 各平台支持的路由类型；FlexE 时隙粒度；云厂商安全产品名称与默认行为。正文已避免写死版本结论。
